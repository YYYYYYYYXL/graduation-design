# 基于深度学习的图像去噪系统

在现有 DnCNN、Restormer、P2N 和 BM3D 实现上提供图片去噪与实验对比。复用本地权重，网页只执行推理，不启动训练。原有任务进度保留在 `task_progress.json` 与 `/api/progress`。

## 启动

继续使用 `denoise310` 环境。

```powershell
conda activate denoise310
python -B -m pip install -r requirements-app.txt
python -B app.py
```

访问 http://127.0.0.1:5000 ，或在项目目录执行 `./start.ps1`。修改后端或模型配置后需重启已有服务。服务使用 Flask / Waitress，仅监听本机，不需要 Node 或数据库。

无参考评分使用 `opencv-contrib-python-headless==4.11.0.86`，不能与其他 OpenCV Python 发行包混装。当前本地环境已将同版本的 `opencv-python-headless` 替换为 contrib 版本。迁移旧环境时，先卸载原 OpenCV Python 包再安装本项目依赖。评分文件在 `third_party/brisque/`，须随项目一起复制；运行期间不联网下载。

## 使用

- **图片去噪**：上传照片、一键处理、查看处理前后图片并下载。默认使用 `Restormer · SIDD`。默认选择不代表它在所有图片上效果最好。
- **实验对比**：五个模型加 BM3D，共六个独立选项。默认勾选所有可用项，每个选项单独出结果，缺失权重显示为不可选。一项失败会显示原因，其他项继续处理。
- **结果**：先看包含“去噪前”的指标表，再看去噪图片；展开“放大同一位置”查看同一像素区域的细节。可下载各张输出图、每项完整 JSON 和整组 CSV。

输入支持 PNG、JPEG、WebP、BMP、HEIC/HEIF，单次上传合计最多 50 MB，原图最多 1 亿像素，每边至少 11 像素。照片按拍摄方向转正后，大于 400 万像素的图像等比例缩小；下载和评分均针对处理尺寸。灰度转 RGB，透明区域合成至白底，多图 HEIF 仅处理主图，HDR 转为 8-bit RGB。浏览器无法预览 HEIC 时仍可提交。

## 怎样做对比

| 已有图片 | 页面操作 | 主要指标 |
| --- | --- | --- |
| 带噪图和对应干净图 | 上传带噪图，展开参考图区域上传干净图 | PSNR、SSIM，通常越高越接近参考图 |
| 只有带噪图 | 直接上传，不填参考图 | BRISQUE，通常越低质量越好；噪声估计仅作辅助 |
| 只有干净图 | 选择“我有清晰照片”，选择噪声强度 | 自动生成同一份高斯噪声，以原干净图计算 PSNR、SSIM |

参考图必须来自同一场景、尺寸相同、像素位置对齐，系统不自动配准。合成噪声支持 σ=15/25/50，默认 25；随机种子默认 42。噪声在缩小后添加，并统一裁剪、量化。各模型接收相同输入，前端核对输入与参考图的像素摘要，避免把不同输入的结果合并。

同一网络的 DIV2K、SIDD 两个版本可以相互比较，也可以将所有网络与 BM3D 比较。训练设置、数据分布、训练时长都可能影响结果，不能把版本差异全部归因于数据集。单张照片的结论只适用于该照片；若用于论文，需使用未参与训练的图片，按合成噪声与真实噪声分别统计，不能用一张图片宣布某个模型全面最好。

| 页面名称 | 权重文件 |
| --- | --- |
| DnCNN · DIV2K | `checkpoints/dncnn_div2k/best.pth` |
| DnCNN · SIDD | `checkpoints/dncnn_sidd/best.pth` |
| Restormer · DIV2K | `checkpoints/restormer_div2k_batch16/best.pth` |
| Restormer · SIDD | `checkpoints/restormer_sidd_batch16/best.pth` |
| P2N | `checkpoints/p2n_pretrain/best.pth` |
| BM3D · 传统方法 | 无需权重，复用 `denoise_bm3d.py` |

模型列表集中在 `models.json`。DnCNN 的两种保存格式分别使用匹配的现有加载器，严格加载参数；不修改权重。P2N 仅使用现有网络直接推理，不执行单图参数更新，因此不是完整的单图适应实验。网络切换时只缓存一个模型。

神经网络使用 256×256 核心块和 32 像素上下文边界，补齐尺寸后裁回原区域；大图结果可能与整图推理不同。BM3D 使用原有整图实现，噪声强度留空时只从带噪输入估计。CPU 和大图处理可能较慢。

## 指标和参数

- **PSNR / SSIM**：按照输出 PNG 的 8-bit RGB 像素与参考图计算。SSIM 使用逐通道 11×11 高斯窗口，σ=1.5、总体协方差。相同图片的 PSNR 为字符串 `∞`；无参考图时不计算这两项。
- **BRISQUE**：无参考图时，用图像自身的自然统计特征估计感知质量。本项目采用 OpenCV 4.11.0 的 BRISQUE 实现与本地 LIVE-R2 评分文件，按处理尺寸的灰度亮度计算，不额外缩放。分数为 0～100，越低通常越好，不是准确率，也不能证明真实细节得到还原。见 [BRISQUE 接口说明](https://docs.opencv.org/4.11.0/d8/d99/classcv_1_1quality_1_1QualityBRISQUE.html)。
- **噪声估计**：逐 RGB 通道小波估计后取均值，换算成 0～255 像素尺度，仅作辅助。纹理也可能被估成噪声，模糊图也可能有很低的估计值，因此不提供“越低越好”的排名。
- **异常评分**：小于 32 像素边长的图片不计算无参考指标；亮度恒定图不计算 BRISQUE；计算失败或非有限数值记为 `null`，并显示原因，不能用 0 代替失败。
- **效率和规模**：表格分别展示去噪时间、加载时间、总处理时间、网络参数量（M，即百万个参数）和设备。卡片显示权重文件大小与是否分块。BM3D 没有网络参数，显示“不适用”。参数量与文件大小均不是实测内存。

神经网络去噪用时包括分块、设备传输与量化，排除模型加载和磁盘读写；BM3D 用时包含噪声估计及去噪，排除转换和读写。CUDA 计时同步设备。总处理时间包含上传后读图、加载、去噪、写图和指标计算，不含网络上传、浏览器渲染及最后 JSON/CSV 写入。冷热缓存、CPU/GPU 和计时范围影响比较，不能把不同环境用时直接排名为算法优劣。

无参考评分不应代替观察噪点、文字、头发、纹理和颜色。页面不把不同指标相加成“综合总分”，也不自动判定总体最优模型。

## 保存与接口

每项请求保存到 `results/web/<随机编号>/`，包括 `input.png`、`output.png`、可选 `reference.png`、`result.json`、`metrics.csv`。整组 CSV 包含去噪前基线和各成功结果，失败项只显示错误，不填造指标。JSON/CSV 保存尺寸、设备、σ、种子、耗时、参数量、权重大小、指标与输入摘要。未测量值为 JSON `null` / CSV 空值；结果不自动清理。

| 接口 | 用途 |
| --- | --- |
| GET `/api/settings` | 默认模型与上传限制 |
| GET `/api/models` | 当前模型与文件是否存在 |
| GET `/api/history/<id>` | 已有训练日志，缺失则返回空列表 |
| GET `/api/progress` | 原有任务进度 |
| POST `/api/denoise` | 单项去噪，实验页按顺序发起多项请求 |
| GET `/results/<id>/<file>` | 图片及 JSON/CSV 下载 |

接口字段和模块关系见 `docs/系统说明.md`。服务同一时间只接受一个去噪请求，其他请求返回忙状态。关闭页面不会取消已经提交的一项任务，后续模型不会自动继续。

## 主要文件

```text
app.py                  上传、指标计算与结果保存
inference.py            五个权重和 BM3D 的推理入口
models.json             模型注册表
image_quality.py        实验页的无参考质量评分
denoising_metrics.py    现有 PSNR / SSIM 计算
web/                    图片去噪与实验对比页面
third_party/brisque/     BRISQUE 评分文件及许可
task_progress.json      原有任务进度，保持原样
checkpoints/            当前去噪模型权重
归档/                    保留的旧模型权重
```

权重、数据和结果不进入 Git，迁移时需另外复制。此次修改仅更新本地项目，不同步线上演示环境。本项目处理照片颗粒噪声，不承诺修复失焦、运动模糊或恢复已经丢失的内容。
