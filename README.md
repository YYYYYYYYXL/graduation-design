# 基于深度学习的图像去噪系统

在原有 DnCNN、Restormer、P2N 和 BM3D 代码上补充本地网页与统一推理接口。普通用户上传图片获取结果，实验使用者可上传配对 GT、生成固定种子的高斯噪声、比较多个模型并导出真实指标。页面另含模型来源、原始训练日志和原有 20 项任务进度。

## 启动

继续使用已有 `denoise310` 环境；本次已安装网页所需依赖，没有更换 PyTorch。

```powershell
conda activate denoise310
python -B -m pip install -r requirements-app.txt
python -B app.py
```

在浏览器访问 http://127.0.0.1:5000 。也可在项目目录执行 `./start.ps1`。Ctrl+C 停止服务。服务仅监听本机，使用 Waitress，不需要 Node、数据库或云端服务。启动服务不会自动推理或训练。首次运行某个模型时才加载权重。

## 使用

- **普通用户**：选择图片、模型和设备后开始去噪。BM3D 的 σ 留空时从输入估计；神经网络不利用此参数修改权重。
- **实验对比**：上传噪声图及对应干净参考图；或勾选生成高斯噪声，把上传图视为 GT，设置 σ（如 15/25/50）和固定种子。勾选多个模型可依次对比，避免同时占用显存。同一组中每个模型得到相同的量化噪声输入。
- **结果**：查看输入、输出、GT；点击图像查看原尺寸，下载 PNG、单次 CSV/JSON 或本组指标 CSV。没有 GT 时 PSNR/SSIM 为空，页面显示“未测量”。
- **模型与记录**：查看本地权重位置和来源，读取已有 `history.csv`。开源模型没有本项目训练日志时保持为空。
- **任务进度**：原表 4 个模块、20 项功能点的文字及顺序完整保留；原表建议值和当前实际状态分开展示。

输入支持 PNG、JPEG、WebP、BMP，单次上传合计最多 25 MB，每张最多 400 万像素，每边至少 11 像素。系统处理 EXIF 朝向，将灰度转为 RGB，透明图像合成至白底；不缩放图片或自动对齐 GT。参考图必须与输入同尺寸、同内容且空间对齐。

## 模型

配置集中在 `models.json`，文件存在仅表示已提供权重，不表示本次已执行推理验证。切换模型时只缓存一个网络，采用 `weights_only=True` 和严格参数加载。

| 方法 | 本地模型 |
| --- | --- |
| BM3D | 复用 `denoise_bm3d.py`，无需权重 |
| DnCNN | 已有 DIV2K 自训模型；本次下载 KAIR 彩色盲去噪模型 |
| Restormer | 原有官方高斯盲去噪、真实噪声；本次下载官方 σ=25；原有本地自训与导入快照；桌面压缩包的 DIV2K、DIV2K batch16、SIDD batch16 自训模型 |
| P2N | 已有 DIV2K 预训练 U-Net，仅直接推理，不执行单图自监督参数更新 |

**P2N 限制**：完整 P2N 单图适应需要优化网络参数，与当前不训练约束冲突。因此页面明确标注“仅推理”，不能把它的结果称为完整 P2N 自监督实验。已有 `p2n/denoise.py`、`denoise_p2n.py` 保留，但网页不调用。DnCNN 和 P2N 的 SIDD 专用自训权重尚未提供，入口禁用。公开高斯权重不冒充 SIDD 自训结果。

**推理口径**：神经网络采用 256×256 核心块和 32 像素上下文边界，补齐到网络所需尺寸后裁回原尺寸。大图结果可能与整图推理不同，不能将这里的指标直接当作论文官方整图指标。BM3D 使用原有整图实现。CPU 与大图处理可能较慢；内存不足时选择较小图片。切换模型时的加载耗时与推理耗时分别记录。

下载来源及完整本地路径见 `docs/模型来源.md`。新机器补齐开源权重：

```powershell
python -B download_models.py
```

下载器复用已有文件，不覆盖自训权重。自训权重和数据未进入 Git，需要随项目另行保留 `checkpoints/` 和 `data/`。

## 指标与记录

统一按输出 PNG 的 8-bit RGB 像素计算 PSNR 和 SSIM，复用 `denoising_metrics.py`。SSIM 为逐通道高斯 11×11 窗口，σ=1.5、总体协方差。完全相同图像的 PSNR 用字符串 `∞` 表示，未提供 GT 用 JSON `null` 和 CSV 空值表示。

神经网络推理耗时包括分块、传输及输出量化，排除加载和磁盘读写；BM3D 沿用原实现的噪声估计及去噪耗时，排除图像转换和读写。因此计时范围并非完全一致，跨方法比较时应注明。CUDA 计时同步设备。真实噪声输入的 σ 未知时不伪造标签。

每次请求保存到 `results/web/<随机编号>/`：输入 PNG、输出 PNG、可选 GT、`result.json` 和 `metrics.csv`。页面刷新后仍可通过已保存链接访问结果，文件不会自动清理。旧的 `results/` 记录不覆盖。

## 目录与接口

```text
app.py                 本地 HTTP 接口、上传处理、指标和结果保存
inference.py           现有四种方法的统一只读推理入口
models.json            模型名称、来源、权重和日志路径
web/                   普通用户、实验对比、模型与记录、任务进度页面
task_progress.json     原清单内容与实际进度说明
docs/毕业设计任务清单.xlsx  原始任务表，原样复制
docs/系统说明.md         需求、模块关系、接口协议与限制
docs/模型来源.md         下载、导入记录和权重命名
dncnn/ p2n/ restormer/  原有模型实现及 DnCNN 开源权重适配
third_party/           原有 Restormer 源码和 KAIR 许可说明
data/ checkpoints/ results/  既有数据、权重和运行结果
```

`GET /api/models` 模型清单；`GET /api/history/<id>` 原始日志；`GET /api/progress` 原任务和实际状态；`POST /api/denoise` 上传并去噪；`GET /results/<id>/<file>` 读取结果。详细参数见系统说明。

原有数据划分、裁剪、加噪和训练脚本保留供追溯，不会被网页自动执行。根目录 `目录.md` 是历史快照，本 README 描述本次新增系统。
