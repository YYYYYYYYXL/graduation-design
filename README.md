# 基于深度学习的图像去噪系统

在原有 DnCNN、Restormer、P2N 和 BM3D 代码上补充本地网页与统一推理接口。首页仅提供上传预览、一键去噪和图片下载；实验使用者可在独立入口上传配对 GT、生成固定种子的高斯噪声、比较多个模型并导出真实指标。原有 20 项任务清单、模型来源和日志留在本地文件及后端接口，不再占用前端页面。

## 启动

继续使用已有 `denoise310` 环境；本次已安装网页所需依赖，没有更换 PyTorch。

```powershell
conda activate denoise310
python -B -m pip install -r requirements-app.txt
python -B app.py
```

在浏览器访问 http://127.0.0.1:5000 。也可在项目目录执行 `./start.ps1`。Ctrl+C 停止服务。服务仅监听本机，使用 Waitress，不需要 Node、数据库或云端服务。启动服务不会自动推理或训练。首次运行某个模型时才加载权重。

## 使用

- **图片去噪**：上传图片并预览，点击“开始去噪”，查看处理前后图片并下载。默认使用现有 Restormer 官方真实噪声模型，自动选择设备；不要求普通用户理解模型或参数。默认选择不代表它在所有图片上效果最好。
- **实验对比**：先选择“我有带噪照片”或“我有清晰照片”。带噪照片直接处理，可选上传配对干净参考图；清晰照片自动生成轻度/中度/重度高斯噪声（15/25/50），默认中度。四种方法默认勾选，可取消；其他权重在“其他模型版本”展开，随机种子与 BM3D 噪声强度放在高级设置。结果集中展示指标表和并排图片，输入及参考图只展示一次。同组使用相同输入，未提供参考图时只比较图片和用时。
- **结果**：首页显示输入和输出，并提供图片下载；实验页另显示 GT、PSNR、SSIM、耗时及 CSV 导出。没有 GT 时实验指标显示“未测量”。完整 JSON 仍在结果目录保存。
- **模型与记录**：前端已移除管理和日志页面；模型来源见 `models.json` 与 `docs/模型来源.md`，原始日志仍在对应权重目录的 `history.csv` 中。
- **任务进度**：原表 4 个模块、20 项功能点的文字及顺序保存在 task_progress.json；原表建议值与当前实际状态分别记录，不作为用户页面。

输入支持 PNG、JPEG、WebP、BMP、HEIC/HEIF，单次上传合计最多 50 MB，原图最多 1 亿像素，每边至少 11 像素。手机常见的 1200 万或 4800 万像素照片可以直接上传，系统按拍摄方向转正后，自动等比例缩小到 400 万像素以内再去噪；小图保持原尺寸。页面及导出记录注明原始尺寸、处理尺寸和是否缩小，下载图片采用处理尺寸。灰度转为 RGB，透明区域合成至白底。浏览器无法预览 HEIC 时仍可提交，处理后显示图片；多图 HEIF 仅处理默认主图，HDR 按解码器默认转换为 8-bit RGB。

实验参考图必须与输入原图同尺寸、同内容且空间对齐；超过处理尺寸时，两张图应用相同的缩小规则，指标针对缩小后的图片计算。系统不自动对齐参考图，缩小会改变噪声与细节，不应把该结果当作原始分辨率的实验结果。HEIC 解码使用 [Pillow-Heif 官方插件接口](https://pillow-heif.readthedocs.io/en/stable/pillow-plugin.html)。

## 模型

配置集中在 `models.json`，当前 8 个神经网络权重和 BM3D 已通过小图实际推理检查；这仅证明基本流程可用，不代表完整测试集效果结论。切换模型时只缓存一个网络，采用 `weights_only=True` 和严格参数加载。

| 方法 | 本地模型 |
| --- | --- |
| BM3D | 复用 `denoise_bm3d.py`，无需权重 |
| DnCNN | 已有 DIV2K 自训模型；本次下载 KAIR 彩色盲去噪模型 |
| Restormer | 官方高斯盲去噪、真实噪声、σ=25；自训仅保留 DIV2K batch16、SIDD batch16 两套模型 |
| P2N | 已有 DIV2K 预训练 U-Net，仅直接推理，不执行单图自监督参数更新 |

**P2N 限制**：完整 P2N 单图适应需要优化网络参数，与当前不训练约束冲突。因此页面明确标注“仅推理”，不能把它的结果称为完整 P2N 自监督实验。未使用的单图适应入口和训练数据读取代码已清理。DnCNN 和 P2N 的 SIDD 专用自训权重尚未提供，入口禁用。公开高斯权重不冒充 SIDD 自训结果。

**推理口径**：神经网络采用 256×256 核心块和 32 像素上下文边界，补齐到网络所需尺寸后裁回预处理后的尺寸。大图结果可能与整图推理不同，不能将这里的指标直接当作论文官方整图指标。BM3D 使用原有整图实现。CPU 与大图处理可能较慢；内存不足时选择较小图片。切换模型时的加载耗时与推理耗时分别记录；实验页面显示包含读图、加载、推理、写图及指标计算的处理用时。

下载来源及完整本地路径见 `docs/模型来源.md`。新机器补齐开源权重：

```powershell
python -B download_models.py
```

下载器复用已有文件，不覆盖自训权重。自训权重和数据未进入 Git，需要随项目另行保留 `checkpoints/` 和 `data/`。

## 指标与记录

统一按输出 PNG 的 8-bit RGB 像素计算 PSNR 和 SSIM，复用 `denoising_metrics.py`。SSIM 为逐通道高斯 11×11 窗口，σ=1.5、总体协方差。完全相同图像的 PSNR 用字符串 `∞` 表示，未提供 GT 用 JSON `null` 和 CSV 空值表示。

神经网络推理耗时包括分块、传输及输出量化，排除加载和磁盘读写；BM3D 沿用原实现的噪声估计及去噪耗时，排除图像转换和读写。因此计时范围并非完全一致，跨方法比较时应注明。CUDA 计时同步设备。真实噪声输入的 σ 未知时不伪造标签。

每次请求保存到 `results/web/<随机编号>/`：输入 PNG、输出 PNG、可选 GT、`result.json` 和 `metrics.csv`。页面刷新后仍可通过已保存链接访问结果，文件不会自动清理。旧的 `results/` 记录不覆盖。

## 目录与接口

```text
app.py                 本地 HTTP 接口、上传处理、指标和结果保存
inference.py           现有四种方法的统一只读推理入口
models.json            模型名称、来源、权重和日志路径
web/                   图片去噪、实验对比两个页面
task_progress.json     原清单内容与实际进度说明
docs/毕业设计任务清单.xlsx  原始任务表，原样复制
docs/系统说明.md         需求、模块关系、接口协议与限制
docs/模型来源.md         下载、导入记录和权重命名
dncnn/ p2n/ restormer/  原有模型实现及 DnCNN 开源权重适配
third_party/           原有 Restormer 源码和 KAIR 许可说明
data/ checkpoints/ results/  既有数据、权重和运行结果
归档/                   仅保留旧模型、续训断点及压缩包中提取的权重
```

`GET /api/settings` 默认模型和上传限制；`GET /api/models` 模型清单；`GET /api/history/<id>` 原始日志；`GET /api/progress` 原任务和实际状态；`POST /api/denoise` 上传并去噪；`GET /results/<id>/<file>` 读取结果。详细参数见系统说明。

原有数据划分、裁剪、加噪工具继续保留。现用模型的权重、配置和训练日志保留在 checkpoints/。归档目录只存放模型权重；旧代码、文档、云端打包材料、压缩包及归档日志已经清理，压缩包中的权重已先提取到 `归档/压缩包模型/`，旧检查目录里的模型副本移至 `归档/测试模型副本/`。迁移项目时需要单独复制 checkpoints/ 和归档/。

测试脚本、测试说明、缓存、已确认的临时检查结果和截图已从项目移至回收站。原始数据、正式去噪结果、任务清单、模型来源、第三方许可证和运行说明保留。归档脚本不再提供恢复运行入口。

## 当前状态与边界

已完成上传预览、一键去噪、多模型对比、真实指标计算和图片/CSV/JSON 导出。2026-11-06 曾完成现有权重及手机图片处理的基本检查；按后续清理要求，检查脚本与专门检查文档已移除。

本项目处理照片中的颗粒噪声，不承诺修复失焦、运动模糊或把低清图片变成高清图片。未开展新的训练或完整测试集研究；缺少的 SIDD 权重、P2N 单图适应和正式研究实验按实际状态记录，不把功能可用等同于原清单全部完成。
