# 5090专用整包：代码、数据、断点

文件名：`5090专用整包_代码数据断点.zip`。只需上传这一个ZIP到`/root/autodl-tmp/`。包内没有嵌套ZIP或tar，解压一次即可得到`graduation-design/`项目目录。

包括：

- RTX5090专用Restormer代码、20/8起始参数、环境安装和batch试测脚本。
- DIV2K、SIDD完整裁剪训练/验证/测试数据，不含原始大图。
- 最新DIV2K best13/last75、SIDD best16/last33，以及配置与训练历史。

请在新实例的空目录解压，避免覆盖已有同名项目。

```bash
cd /root/autodl-tmp
python3 -m zipfile -e 5090专用整包_代码数据断点.zip .
cd graduation-design
bash setup_remote.sh
```

默认使用`/root/venvs/denoise/bin/python`；若选择其他环境，设置`DENOISE_PYTHON`为对应Python绝对路径。5090需要兼容Blackwell的PyTorch构建，安装脚本对齐旧服务器的PyTorch2.8.0+CUDA12.8。若此前已装好依赖，可以跳过setup。

## 有卡后先试测

```bash
/root/venvs/denoise/bin/python -B probe_restormer.py --dataset sidd
```

试测仅更新临时模型，不会改写原best/last，也不会自动开始正式训练。20/8仍是未实测起点。试测会生成`results/codex_batch_probe_*/codex_tuned_profile.json`，记录候选batch中的显存、速度和推荐值。

## 继续SIDD

使用试测推荐配置时，将下面的路径替换成实际生成的配置路径：

```bash
mkdir -p logs
nohup bash resume_sidd.sh --profile /完整路径/codex_tuned_profile.json > logs/restormer_sidd.log 2>&1 < /dev/null &
tail -f logs/restormer_sidd.log
```

直接使用20/8起始配置时去掉`--profile ...`。首次会复制迁移的SIDD断点，从第34轮接着跑，保留原始第33轮last。新结果位于`checkpoints/remote_5090/restormer_sidd_fast_5090/`。

## DIV2K新训练

```bash
mkdir -p logs
nohup bash run_gpu.sh div2k > logs/restormer_div2k.log 2>&1 < /dev/null &
```

从零开始，结果位于`checkpoints/remote_5090/restormer_div2k_fast_5090/`，不覆盖旧best13和last75。同一张卡先运行一项正式训练。

## 如需手动把已有分包合并

把以下三项和使用说明放入同一个ZIP即可：

1. `远程/5090/远程代码_5090.zip`
2. `远程/数据/裁剪数据.zip`
3. `远程/断点/checkpoints.tar.gz`

这种手动方式生成的是嵌套分包，仍需按上级README逐层解压。提供的`5090专用整包_代码数据断点.zip`已经展开这些内容，只有一次解压，不需要再手动打包。
