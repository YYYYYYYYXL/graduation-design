# 项目归档

此目录保存当前推理系统不再直接使用的内容，采用移动归档，不永久删除。

## 2026-11-05

`2026-11-05/移动清单.json` 记录每项原位置和归档位置，归档内继续沿用原相对目录结构。

- **旧模型**：Restormer 另一批 DIV2K、SIDD 初期快照、来源待补充的导入快照，以及没有成品权重的旧启动目录。
- **续训断点**：保留模型的 `last.pth`；当前 `best.pth`、配置和训练日志留在 checkpoints。
- **训练代码和工具**：三个模型的训练入口、统一云端入口、训练公共工具、性能探测、续训准备、打包工具和云端配置/脚本。
- **旧材料**：远程部署包、答辩 PPT、开题精简版和历史目录说明。

当前保留 8 个权重：Restormer 自训 DIV2K batch16、SIDD batch16，DnCNN 自训 DIV2K，P2N DIV2K 预训练，以及 DnCNN 官方彩色盲去噪和 Restormer 官方高斯盲去噪、真实噪声、σ=25。模型注册表已去除归档版本，缺失的 SIDD DnCNN/P2N 入口继续禁用。

本次选择按用户指定的保留方案执行，不代表已比较不同训练批次的去噪效果。未启动训练、推理或测试。

## 恢复

停止使用涉及的文件后，按移动清单将归档项移回原位置。若目标已经存在，先决定使用哪个版本，不能直接覆盖。训练脚本依赖项目根目录、模型模块和数据路径，不能直接在归档子目录运行；需要恢复相关脚本/配置到原位置。若恢复旧模型并希望页面可选，还需在 `models.json` 恢复其记录。

原始数据、正式结果、真实实验记录、任务清单、当前模型代码和数据处理工具均未移入归档。归档大文件及原有未跟踪材料不加入 Git；备份或搬迁时须另行复制本目录。
