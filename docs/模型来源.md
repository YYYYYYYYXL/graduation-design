## 登记方式

在 `models.json` 添加独立 id、显示名、method、相对 path、source、note，可选 history。仅登记可信来源的兼容权重。自训模型沿用 `<方法>_<数据集/批次>/best.pth`，开源文件放在 `<方法>_official/` 并保留上游文件名以便追溯。新增记录后重启服务读取配置。

本地权重受 `.gitignore` 排除；交付或迁移时需另外复制所需 `checkpoints/` 文件，不能只复制 Git 仓库后假定自训权重也已包含。
