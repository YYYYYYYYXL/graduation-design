# 系统需求与实现说明

## 需求与边界

普通用户需要选择图片、去噪方法和设备，查看原图及结果并下载。实验使用者需要固定输入和噪声条件，选择多个已有模型，上传配对 GT，查看真实 PSNR、SSIM、耗时及导出记录。模型页面需要区分官方和自训权重，显示缺失情况和原始训练日志。任务页面需要保留原清单 4 个模块、20 个功能点。

本系统为单机、本地浏览器使用，不包含用户账号、远程部署、在线训练或无关业务。模型数据不发送到云端。网页不启动本地或云端训练，也不调用会更新参数的 P2N 适应流程。缺失权重不能随机初始化后冒充去噪模型。

## 模块关系

1. `web/index.html`、`style.css`、`app.js`：页面、表单和结果显示；原生浏览器功能，不需要构建工具。
2. `app.py`：接受 multipart 上传、格式检查、统一 RGB、合成噪声、调用推理、计算指标并保存记录。
3. `inference.py`：读取模型注册表，复用原有加载器或独立开源适配器，采用严格参数匹配，提供 BM3D 与三类神经网络推理。
4. `models.json`：权重、显示名、来源、训练记录路径。管理者只需按相同格式登记兼容模型，无需改前端。
5. `results/web/`：每次请求一个随机目录。训练记录来自 `checkpoints/` 已有 CSV，不由网页生成。
6. `task_progress.json`：原表字段与当前状态分开存储；原始 XLSX 原样保存在 docs。
7. `归档/2026-11-05/`：旧权重、续训断点、训练/云端辅助文件和旧答辩材料；移动清单记录恢复路径，网页不读取归档中的模型。

同一时间仅执行一个去噪请求，其他请求返回 409，避免模型切换和显存竞争。实验比较由浏览器按选定顺序串行请求，一项失败显示错误，后续项目继续。界面处理期间锁定输入，保证同组参数一致。结果目录由随机编号生成，不使用上传文件名作为路径。

## 接口

| 方法与路径 | 用途 |
| --- | --- |
| GET `/` | 用户界面 |
| GET `/api/models` | 所有模型及文件是否存在；不加载或运行模型 |
| GET `/api/history/<model_id>` | 原始 CSV 字段、行与说明；缺失返回空列表 |
| GET `/api/progress` | 原表字段和实际状态 |
| POST `/api/denoise` | 上传并进行一次推理 |
| GET `/results/<run_id>/<filename>` | 获取允许的 PNG、CSV、JSON 文件 |

`POST /api/denoise` 表单字段：

| 字段 | 类型/默认值 | 说明 |
| --- | --- | --- |
| image | 必选文件 | 噪声图；synthetic=true 时为干净原图 |
| model | 必选字符串 | models.json 中的 id |
| reference | 可选文件 | 同尺寸、已对齐的 GT；合成模式不能额外提供 |
| device | auto | auto / cpu / cuda，BM3D 实际使用 CPU |
| sigma | 空 | 0～255；BM3D 空值时估计；合成噪声时必填 |
| synthetic | false | true 时生成固定种子高斯噪声 |
| seed | 42 | 0～4294967295 的整数，仅合成时参与加噪 |

响应包含结果编号、模型、UTC 时间、尺寸、实际设备、sigma、合成标记与种子、推理和加载耗时、是否分块、输入和输出指标、各结果下载 URL，以及模型说明。未测量指标为 null；PSNR 无穷大为字符串 `∞`。CSV 中未测量值为空。

错误状态：400 为参数或图片错误，404 为未知记录/模型，409 为模型忙，413 为上传超限，500 为依赖、模型加载或推理错误。服务日志记录异常，不将堆栈返回网页。模型不兼容时失败，不使用 `strict=False` 静默丢弃参数。

## 实验口径和已知限制

- 指标只比较量化后的 RGB 图像，GT 不进入神经网络或 BM3D。
- 上传真实噪声图时不再添加噪声；合成模式使用 NumPy 局部随机生成器，sigma 按 8-bit 像素尺度定义，结果裁剪、取整后供所有模型使用。
- P2N 页面结果是监督预训练网络的直接推理基线，不等同于 P2N 单图自监督适应结果。
- 图像分块会改变 Restormer 的全局上下文，也可能带来块边界差异；报告中应记录分块口径。
- CPU、GPU、模型冷热加载、输入尺寸和不同计时范围都会影响耗时，不把不同环境的历史数字直接并成同一实验。
- 原始训练日志的验证指标、网页单图指标和完整测试集指标含义不同，界面分别展示，不编造或混用。
- 缺少 DnCNN/P2N 的 SIDD 专用自训权重；开源高斯模型只能按其真实来源使用。
- 用户中途关闭页面不会中断服务器正在进行的一次推理；同组后续请求不会自动继续。无需数据库，已完成结果仍保存在本地。
- 上传/结果目录不自动删除，应在不使用对应结果时自行清理 `results/web/`，不能把既有训练日志、源数据或正式结果当作临时文件。
