# RTX 5090 32GB

使用本目录的`远程代码_5090.zip`，另上传共用数据ZIP和断点tar.gz。解压与环境安装步骤见上级README。

起始batch为训练20、验证8；这是未实测起点。先运行`/root/venvs/denoise/bin/python -B probe_restormer.py --dataset sidd`，获取显存与速度实测结果。保留显存余量的吞吐推荐值比单纯占满显存更有用。

续训示例：

```bash
cd /root/autodl-tmp/graduation-design
mkdir -p logs
nohup bash resume_sidd.sh --profile /完整路径/codex_tuned_profile.json > logs/restormer_sidd.log 2>&1 < /dev/null &
tail -f logs/restormer_sidd.log
```

不试测而直接使用起始20/8时，去掉`--profile ...`；仍需观察是否显存不足及实际速度。DIV2K新训练用`bash run_gpu.sh div2k`。新结果在`checkpoints/remote_5090/`。

需要PyTorch CUDA 12.8或更新兼容构建；建议与旧服务器对齐为PyTorch2.8.0+cu128。RTX5090与某些5090D型号的显存容量可能不同，请以实例实际型号/显存为准。本包只包含Restormer。
